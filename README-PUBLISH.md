# BotNest Corporate Website

Static website for GitHub Pages.

## Publish
1. Back up the current repository.
2. Upload the contents of this folder to the repository root.
3. Commit and push to the configured GitHub Pages branch.
4. Keep the `CNAME` file containing `botnest.in`.

## Pages
- `index.html` — corporate homepage
- `solutions.html` — home, office and IoT solutions
- `products.html` — searchable proposed product catalogue
- `app.html` — BotNest Automations app overview
- `about.html` — company profile
- `contact.html` — enquiry form (opens user's email client)
- `privacy-policy.html` and `terms-and-conditions.html`

## Notes
The product catalogue is a proposed roadmap. Listings do not claim stock, manufacture or app compatibility. There is no public pricing displayed.
The enquiry form uses a `mailto:` action and does not submit to a server.
Legacy Academy account/course pages have been removed from this corporate deployment. Keep a backup of the previous repository before replacing files.
